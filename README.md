# CMGeorge's Home Assistant Add-ons

This repository contains Home Assistant add-ons for various integrations.

## Add-ons

### Epever Integration Add-on
Home Assistant integration for Epever solar charge controllers.

### Sabiana Integration Add-on  
Home Assistant integration for Sabiana HVAC systems.

## Installation

1. In Home Assistant, go to **Supervisor** > **Add-on Store**
2. Add this repository by clicking the menu in the top-right corner and selecting **Repositories**
3. Add the URL: `https://github.com/CMGeorge/ha_repository`
4. The add-ons from this repository should now be available in your add-on store
